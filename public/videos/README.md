# Video Uploads Directory / مجلد الفيديوهات

You can put your video files (.mp4 or .webm) directly here!
يمكنك وضع ملفات الفيديو (.mp4 أو .webm) مباشرة في هذا المجلد!

Example / مثال:
- `public/videos/reel-1.mp4` -> In the portfolio data, set `videoUrl: '/videos/reel-1.mp4'`
- `public/videos/youtube-1.mp4` -> In the portfolio data, set `videoUrl: '/videos/youtube-1.mp4'`
- `public/videos/showreel.mp4` -> In the portfolio data, set `videoUrl: '/videos/showreel.mp4'`

Recommended settings:
- Codec: H.264 or H.265 (MP4)
- Resolution: 1080x1920 (for Reels) or 1920x1080 (for YouTube)
- File size: 5MB to 20MB per clip for instantaneous web loading.
